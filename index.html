Assinaturas de e-mail Pratika

Preencha os dados do funcionário, confira a prévia e clique em Copiar assinatura. Instagram, LinkedIn, WhatsApp e telefone ficam clicáveis para quem recebe.

Funcionário

Deixe em branco para o botão abrir o WhatsApp da empresa.

Links da empresa

Valem para todas as assinaturas e ficam lembrados neste navegador.

Como instalar

  1. Na primeira vez, confira os Links da empresa (Instagram, LinkedIn e WhatsApp).
  2. Preencha os dados do funcionário e confira a prévia.
  3. Clique em Copiar assinatura.
  4. Gmail: Configurações → Ver todas as configurações → Assinatura → Criar nova → cole (Ctrl+V).
  5. Outlook: Configurações → Email → Assinaturas (ou Arquivo → Opções → Email → Assinaturas no app) → cole.
  6. Envie um e-mail de teste para o seu celular e toque em cada ícone.

Dica: se o programa de e-mail tiver um campo para código HTML (Thunderbird, Apple Mail, alguns sistemas), use Copiar código HTML.

As imagens da assinatura ficam hospedadas neste mesmo site. Por isso a assinatura funciona para quem recebe sem nenhuma configuração extra.
